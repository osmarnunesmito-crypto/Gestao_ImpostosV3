Escopo do Projeto

Descreva, de forma clara, o resultado que o projeto deve alcançar. Pense no "para quê" do projeto.

Quais indicadores ou condições vão provar que o projeto deu certo? Seja específico e mensurável.

O que você está considerando como verdadeiro para o projeto acontecer? Registrar ajuda a evitar surpresas.

Limitações que o projeto deve respeitar: tempo, dinheiro, recursos, tecnologia, normas etc.

Entregas Principais

Liste os produtos, documentos ou resultados concretos que devem ser entregues ao final de cada etapa. Ex: "Projeto arquitetônico aprovado", "Site publicado", "Treinamento realizado".

Fora do Escopo

Registre aqui o que o projeto NÃO vai fazer. Isso evita que outras pessoas criem expectativas incorretas. Ex: "Não inclui compra de móveis", "Não cobre manutenção após a entrega".
